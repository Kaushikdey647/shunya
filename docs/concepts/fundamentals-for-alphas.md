# Fundamentals for alphas

Statement and valuation fields are normalized in **`shunya/data/fundamentals.py`** and exposed on the alpha context as **`fun.<Name>`** in Alpha Studio (keep in sync with **`ui/src/alphaEditor/alphaDslCatalog.ts`**).

## Statement and ratio fields (`fun.*`)

These map to **`_FUNDAMENTAL_FIELD_SPECS`** in code (income / cash flow / balance sheet / ratio sources).

| `fun.*` / column | Source bucket | Plain-English meaning |
|------------------|---------------|----------------------|
| `Revenue` | income_statement | Top-line sales over the reporting period. |
| `Net_Income` | income_statement | Profit after expenses; bottom line of the P&amp;L. |
| `EPS_Diluted` | income_statement | Net income per share if all dilutive securities convert. |
| `Operating_Cash_Flow` | cash_flow_statement | Cash generated by core operations. |
| `Free_Cash_Flow` | cash_flow_statement | Operating cash flow minus capex; funds available to owners/debt. |
| `Total_Assets` | balance_sheet_statement | Everything the company owns (book). |
| `Total_Equity` | balance_sheet_statement | Assets minus liabilities; book value of equity. |
| `Total_Debt` | balance_sheet_statement | Interest-bearing obligations (definition follows data vendor). |
| `Current_Ratio` | liquidity_ratios | Current assets / current liabilities; short-term liquidity. |
| `Gross_Margin` | profitability_ratios | Gross profit / revenue; pricing power vs COGS. |
| `Operating_Margin` | profitability_ratios | Operating income / revenue; core profitability. |
| `Return_On_Assets` | profitability_ratios | Net income / assets; asset efficiency. |
| `Return_On_Equity` | profitability_ratios | Net income / equity; shareholder return on book equity. |
| `Debt_To_Equity` | solvency_ratios | Leverage relative to equity book value. |
| `Free_Cash_Flow_Yield` | solvency_ratios | Free cash flow relative to price/enterprise context (vendor definition). |
| `Price_To_Earnings` | valuation_ratios | Price per unit of earnings; **lower** often reads as “cheaper” vs earnings power. |

### Example: value tilt on FCF yield

```python
def alpha(ctx):
    return cs.zscore(fun.Free_Cash_Flow_Yield)
```

## Daily / price-linked fields (`fun.*`)

From **`DAILY_FUNDAMENTAL_FIELDS`** (stored in `fundamentals_daily`; same names on the alpha context).

| `fun.*` | Meaning |
|---------|---------|
| `Market_Cap` | Shares × price; size of the equity. |
| `Enterprise_Value` | Debt-inclusive firm value; common in value ratios. |
| `Trailing_PE` | Price / trailing twelve-month earnings. |
| `Forward_PE` | Price / analyst forward earnings consensus (vendor-dependent). |
| `PEG_Ratio` | P/E relative to expected growth; **model-dependent**. |
| `Price_To_Book` | Price / book value per share. |
| `Dividend_Yield` | Dividends / price. |
| `Beta` | Sensitivity vs a reference index (estimation window per vendor). |
| `Shares_Outstanding` | Share count; scales flows to per-share figures. |

### Example: quality tilt on ROE

```python
def alpha(ctx):
    return cs.zscore(fun.Return_On_Equity)
```

To **size-adjust** in research, combine with `fun.Market_Cap` ranks in a second step (see [Alpha design](alpha-design-rank-zscore-and-gates.md)); the DSL exposes `ts.*` helpers listed in `alphaDslCatalog.ts`—avoid calling non-catalog helpers unless your wrapped template imports them.

## Using fundamentals well

- **Look-ahead:** fundamentals are reported with **lags**; production systems align filing dates. Research panels may forward-fill; know your **`finTs`** / provider assumptions.
- **Comparability:** prefer **ratios** or **cross-sectional z-scores** (`cs.zscore`) across peers rather than raw levels.
- **Missing data:** use **`cs`** transforms that tolerate NaNs as implemented, or gate with `jnp.where` / `trade_when` patterns.
